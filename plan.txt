# AsyncStorage → MMKV Migration Plan

## Overview
Replace all AsyncStorage usage with AppStorage (MMKV wrapper) for synchronous, high-performance storage.

## Migration Pattern
- Import: `import AsyncStorage from "@react-native-async-storage/async-storage"` → `import AppStorage from "@/src/utils/storage/storage"`
- Methods:
  - `AsyncStorage.getItem()` → `AppStorage.getItemSync()` (synchronous)
  - `AsyncStorage.setItem()` → `AppStorage.setItemSync()` (synchronous)
  - `AsyncStorage.removeItem()` → `AppStorage.removeItemSync()` (synchronous)
  - `AsyncStorage.multiGet([...])` → `Promise.all([...].map(key => [key, AppStorage.getItemSync(key)]))`
  - `AsyncStorage.multiSet([...])` → `[...].forEach(([k,v]) => AppStorage.setItemSync(k,v))`
  - `AsyncStorage.multiRemove([...])` → `[...].forEach(key => AppStorage.removeItemSync(key))`
  - `AsyncStorage.getAllKeys()` → `AppStorage.getAllKeysSync()` (synchronous)
  - `AsyncStorage.clear()` → `AppStorage.clearSync()` (synchronous)
- Remove `await` and `Promise.all()` where using sync methods
