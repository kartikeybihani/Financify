CACHE LOADING STRATEGY - EAGER VS LAZY
=======================================

CURRENT IMPLEMENTATION (Eager Loading)
--------------------------------------

How it works:
1. Home Screen: useUnifiedFinancialData hook loads unified cache synchronously
   - Happens when HomeScreen component mounts
   - Cache read: ~0.1-1ms (MMKV is very fast)
   - Shows data instantly

2. Insights Tab: Each section loads its cache when InsightsScreen mounts
   - Transactions cache: Loads when insights screen mounts
   - Spending cache: Loads when insights screen mounts
   - Budget cache: Loads when insights screen mounts
   - Investment cache: Loads when insights screen mounts
   - Recurring cache: Loads when insights screen mounts

Performance:
- Synchronous cache reads: ~0.1-1ms each (microseconds, not milliseconds)
- Total cache reads: ~5-10ms for all caches
- No network calls, just storage reads
- Non-blocking (doesn't delay UI render)

Current Behavior:
- If user opens app → Home cache loads (instant)
- If user navigates to Insights → All insights caches load (instant)
- If user never visits Insights → Caches still load (but it's instant, so no issue)
